# Fieldnotes display face

`caveat-latin-600-normal-5.2.8.woff2` is the Latin, normal, weight 600 face from
[@fontsource/caveat 5.2.8](https://www.npmjs.com/package/@fontsource/caveat/v/5.2.8).
The package archive was checked against its npm SHA-512 integrity value.
The included `Caveat-OFL-5.2.8.txt` applies to this font.

The site bundles this file through Topcoat. Alegreya Sans and JetBrains Mono
continue to use the existing self-hosted Fontsource declarations.
